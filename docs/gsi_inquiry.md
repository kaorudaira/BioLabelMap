## 文面

件名:地理院タイルを端末に保存して使うアプリの利用手続について

国土地理院 ご担当者様

個人で開発している、昆虫標本ラベルの記録アプリ(Android、将来はiPhone)について、地理院タイルの利用手続を教えてください。

【アプリの概要】
- 山間部など圏外の場所で、採集地点をGPSで記録するための個人用のアプリです。
- 現在地を地図上に表示するため、地理院タイル(標準地図、淡色地図、写真、陰影起伏図、色別標高図)を使います。
- 配布は、開発者本人と少人数の協力者への限定的なものを想定しています。販売や広告表示は予定していません。
- 出典の表示と、地理院タイル一覧へのリンクは、アプリの地図画面と設定画面に載せます。

【お尋ねしたいこと】
1. 圏外でも地図を使えるよう、利用者が指定した範囲(約20km四方、最大ズームまで)の地理院タイルを、利用者の端末に一時的に保存して表示することは、「国土地理院コンテンツ利用規約」のもとで可能でしょうか。承認申請は必要でしょうか。
2. 申請が必要な場合、基本測量成果の複製・使用の承認申請と、基本測量成果以外の利用のどちらに当たりますか。タイルの種類(標準地図・淡色地図・写真・陰影起伏図・色別標高図)ごとに扱いが違う場合は、その区別も教えてください。
3. 保存の方法は、アプリ内で利用者が範囲を選び、1回ずつ手動でまとめて取得する形です。サーバーへの負荷を抑えるため、同時接続数と取得速度に上限を設けます。取得してよい量、速度、時間帯などに、守るべき目安はありますか。
4. 端末内に保存したタイルを、アプリのバックアップ(利用者自身のファイル)に含めない運用にする予定です。ほかに注意すべき点があれば教えてください。
